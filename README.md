# data-for-lab6

Навчальні дані для лабораторної роботи 6 «Контроль якості даних» (курс «Інжиніринг даних», Одеська політехніка).

Файли в `data/`:

- `fact_sales_control.csv` — контрольний пакет продажів (без дефектів);
- `fact_sales_problem.csv` — проблемний пакет продажів (з дефектами);
- `dim_product.csv`, `dim_customer.csv` — довідники товарів і клієнтів.

Інструмент: OpenRefine (запускається в Codespaces, див. методичку).
